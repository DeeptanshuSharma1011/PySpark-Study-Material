# ⚡ PySpark Learning Hub

A hands-on learning repository covering **Apache PySpark**, **DataFrames**, **data cleaning**, **aggregation**, **MLlib**, and **Databricks**. This repo contains practical notebooks, examples, and implementations built while learning PySpark for **Data Engineering and AI/ML workflows**.

## 🎯 About This Repository

This repository is designed as a structured learning path from **PySpark fundamentals → DataFrame operations → data preprocessing → aggregations → machine learning → Databricks**.

The focus is on learning concepts through practical implementation rather than only theoretical explanations.

## 📚 Learning Roadmap

### 01. PySpark Introduction

* Introduction to Apache Spark
* What is PySpark?
* Spark architecture and distributed processing basics
* Creating and working with a Spark session

### 02. DataFrame Operations — Part 1

* Reading datasets
* Schema checking
* Checking data types
* Selecting columns
* Column indexing
* Using the `describe()` option
* Adding new columns
* Dropping columns

### 03. Handling Missing Values

* Identifying missing values
* Working with `null` values
* Filling missing values
* Dropping missing values
* Basic data-cleaning workflows

### 04. DataFrame Operations — Part 2

* Filtering DataFrames
* Comparison operators
* `==` operator
* `&` for AND conditions
* `|` for OR conditions
* `~` for NOT conditions
* Combining multiple filtering conditions

### 05. GroupBy & Aggregate Functions

* Grouping DataFrames
* `groupBy()`
* Aggregate functions
* `sum()`
* `avg()`
* `min()`
* `max()`
* `count()`
* Combining grouping and aggregation operations

### 06. MLlib

* Introduction to Spark MLlib
* MLlib installation/setup
* Preparing data for machine learning

* Understanding Spark's ML pipeline ecosystem

### 07. Databricks Introduction

* Introduction to Databricks
* Understanding Databricks notebooks
* Working with Spark on Databricks
* Databricks compute and clusters
* Basic Databricks workflow

### 08. Linear Regression with Databricks

* Creating a Databricks cluster
* Working with a single cluster
* Preparing the dataset
* Feature preparation

* Training the model
* Generating predictions
* Evaluating the model
